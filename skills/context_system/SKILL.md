# Answering from the company's context

1. Start from the workspace: the knowledge files and the ontology say what the company tracks and
   where. Check how fresh a file is before trusting it.
2. Search the connected tools for the specifics the question names: the account, the deal, the
   meeting. Try the names people actually use (nicknames, ticket ids, product names).
3. Read the items you cite in full: a thread's replies can correct its first message.
4. Say what you could not find or confirm, and which tool it would be in.
5. Cite each fact: the tool and the item (an email's subject and date, a Slack message's channel).
